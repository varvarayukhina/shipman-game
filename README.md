# Дело: прототип (4 главы)

Детективная игра в браузере по мотивам реального дела врача Гарольда Шипмана. Ты следователь: читаешь документы дела, ловишь противоречия, предъявляешь документы на допросе. Прохождение занимает около часа.

Играть: https://varvarayukhina.github.io/shipman-game/

Прогресс сохраняется в этом браузере. На другом устройстве или после очистки данных сайта игра начнётся сначала.

О фактах. Реальное имя только у самого Шипмана. Пациентки, родственники, свидетели, фирмы и все документы в игре вымышлены по мотивам отчёта Shipman Inquiry. Фотографии сгенерированы нейросетью, людей на них нет. Реплики допроса, часы срока задержания и метки времени в журнале правок придуманы для игры.

Что хочется узнать: где стало скучно или непонятно, какая механика понравилась, на каком месте бросила.
