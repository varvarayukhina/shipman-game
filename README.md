# Дело: прототип (4 главы)

Детективная игра в браузере по мотивам реального дела. Имя врача скрыто до финала, можно пробовать угадать, чьё это дело. Ты следователь: читаешь документы дела, ловишь противоречия, предъявляешь документы на допросе. Прохождение занимает около часа.

Играть: https://varvarayukhina.github.io/shipman-game/

Прогресс сохраняется в этом браузере. На другом устройстве или после очистки данных сайта игра начнётся сначала.

О фактах. Реальное имя только у самого Шипмана. Пациентки, родственники, свидетели, фирмы и все документы в игре вымышлены по мотивам отчёта Shipman Inquiry. Реплики допроса, часы срока задержания и метки времени в журнале правок придуманы для игры.

Что хочется узнать: где стало скучно или непонятно, какая механика понравилась, на каком месте бросила.

Главная страница это каталог дел. Дела №1–4 открываются по `?game=1` … `?game=4`. Дело №5 «Бригада» это игра для компании на несколько телефонов, страница `team.html`: у каждого игрока своя роль и свои бумаги, ответы вводит ведущий. Ссылка `team.html?role=sc` открывает сразу нужную роль (sc, vid, rec, dos, lead).
